Drive DJ Finder v1.5.2 SAFE THROUGHPUT
Build: 2026-08-19

今回の変更

1. MusicBrainz全曲辞書の0件対策
- HTML側の辞書URLにv1.5.2の版番号を付け、古いPWAキャッシュを回避します。
- OCR開始時に辞書が0件なら、日時付きURLで一度だけ再取得します。
- 成功時は検索インデックスとアーティスト辞書を作り直します。
- 診断にMB辞書件数、再読込回数、成功、所要時間、失敗理由を残します。
- 再取得に失敗しても動画OCR自体は止めず、要確認として継続します。

2. 複数アーティストを保持
- 連名全体の完全一致を最優先します。
- 完全一致しない「、」「;」「feat.」「ft.」「with」の連名だけを分割し、各名を個別補正して再結合します。
- 「椎名林檎、向向井秀徳」は「椎名林檎、向井秀徳」になります。
- 単独アーティストの部分一致で先頭名だけに切り詰める経路を避けました。

3. 精度優先のOCR再利用
- 同じBPM、同じ色KEY、ほぼ同一の曲名画像、ほぼ同一のアーティスト画像が揃う行だけTesseract結果を再利用します。
- 曲名画像だけで再利用しないため、似た別曲や別アーティストへの誤伝播を抑えます。
- PaddleOCRの再利用条件も同じ4条件に厳格化しました。
- 診断にTESS固有行、TESS再利用、PADDLE再利用を表示します。

確認済み
- HTML内JavaScript、Service Worker、共有Worker、manifestの構文検査: 合格
- 10,781曲の埋込データとCSV整合性: 合格
- PWA/iPhone公開ファイル整合性: 合格
- 実MusicBrainz辞書: 306,682件を読込、既知曲ペア照合に合格
- 複数アーティスト保持テスト: 合格
- BPM/KEY/曲名/アーティストが不一致のOCRキャッシュ拒否テスト: 合格

診断で見る場所
- MB辞書: 0でなければ全曲辞書が有効です。
- MB再読込 / MB再読込ms: 初期キャッシュが古かった場合だけ増えます。
- TESS固有行 / TESS再利用: 再利用で省略できた行数を確認できます。
- TESS CACHE: その診断行は安全条件を満たして再利用されています。
- 複数名保持: 連名を分割補正して保持した回数です。

既知の限界
- 録画フレーム自体で文字の上端・下端が欠けている場合、OCR単体では完全復元できません。
- v1.5.2は別フレームの同一行、全曲辞書、手動学習の順で救済し、確証がない行は自動確定しません。
- 実動画での短縮時間はTESS再利用件数によって変わるため、診断値で判定します。
